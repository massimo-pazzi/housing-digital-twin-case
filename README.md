# Цифровой двойник жилого фонда Москвы — продуктовый кейс

Кейс менеджера продукта в IT с фокусом на ИИ: концепция платформы
предиктивного обслуживания инженерных систем жилых домов Москвы, которую я
прорабатывал в Лаборатории Наносемантика по запросу Мосстратегии (Департамент
экономической политики и развития города Москвы), апрель–май 2026 года.

Кейс в работе. Сейчас в репозитории:

- [`demo/`](demo/) — кликабельный прототип интерфейса на демонстрационных данных;
- [`research/`](research/) — сверка фактов исходных материалов с первоисточниками.
